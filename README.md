# Minishell

## Description
Minishell is a minimalist shell program written in C that replicates the core behavior of bash. The goal of this project is to dive deep into process creation, file descriptors, and terminal management. It features a robust Lexer/Parser combination to process standard inputs, handles environment variable expansion (`$VAR` and `$?`), manages pipes (`|`) for interconnecting commands, and seamlessly redirects standard streams (`<`, `>`, `>>`, `<<`). It correctly replicates signal behaviors (`ctrl-C`, `ctrl-D`, `ctrl-\`) in various execution contexts and implements essential built-ins such as `echo`, `cd`, `pwd`, `export`, `unset`, `env`, and `exit`.

## Instructions

### Compilation
The project uses a standard `Makefile` to compile. Run the following command at the root of the repository:
```bash
make
```
This will generate the `minishell` executable.

### Execution
Run the shell by simply executing the binary:
```bash
./minishell
```
You will be greeted with the `minishell$ ` prompt, where you can type your commands just like in bash.

### Cleanup
To remove the compiled object files:
```bash
make clean
```
To remove both the object files and the `minishell` executable:
```bash
make fclean
```

## Resources

During the development of this project, the following resources were consulted:
- **GNU Bash Manual**: Used extensively as the ground truth reference for expected shell behaviors (quoting, pipelines, signals).
- **POSIX Programmer's Manual (man pages)**: For detailed information on authorized system calls like `fork`, `execve`, `waitpid`, `pipe`, `dup2`, `tcsetattr`, and `tcgetattr`.
- **Readline Library Documentation**: To properly implement the `readline`, `add_history`, and understand the implications of memory management in history.

### AI Usage
AI assistants were utilized solely during the debugging and refinement phases of this project:
- Identifying complex memory leaks (e.g., heap-buffer-overflows in edge cases of string expansion and valueless environment variables).
- Providing static analysis of the parsing architecture to ensure norminette compliance and zero unclosed file descriptors.
- No core architecture or initial implementations were generated by AI.
